# BI Digital Knowledge Corner — Final

Prototype website untuk tugas akhir magang sebagai media pendukung diseminasi informasi kebanksentralan.

## Struktur
- `app.py` — aplikasi Streamlit
- `assets/` — ilustrasi hero dan kartu topik
- `data/` — penyimpanan feedback/aktivitas saat aplikasi berjalan
- `requirements.txt` — dependency

## Jalankan
```bash
pip install -r requirements.txt
streamlit run app.py
```

Catatan: prototype ini bukan aplikasi resmi Bank Indonesia. Konten dan tautan perlu diverifikasi oleh unit terkait sebelum penggunaan resmi.
